# Row Counter

Count your knitting rows from Raycast. For people who, like me, knit a lot while on their laptops.

- **Add Row** - adds a row and shows the current row
- **Remove Row** - removes a row if you added one by accident (never goes below 0)
- **Show Row Count** - shows how many rows you've done
- **Reset Row Counter** - resets the count to 0

The count is stored locally, so it survives Raycast and Mac restarts. Add Row also shows the current row as its subtitle in the Raycast search.

## Tips

- Assign a global hotkey to **Add Row** (Raycast Settings > Extensions > Row Counter) to add rows without opening Raycast.
- Give each command a short alias (for example `counter`, `counter remove`, `counter see` and `counter reset`) to run them quickly from the search bar.
